# restaurant-management
This project is a restaurant management system developed using pure PHP with an MVC architecture and MySQL database management through phpMyAdmin.

The application includes a complete authentication system, session management, image upload handling, and full CRUD operations. The platform was designed to help administrators efficiently manage restaurant operations, reservations, orders, tables, and menu items.

The system features an admin login page followed by a dashboard that displays restaurant statistics and allows generating daily reports based on a selected date. The reports include information about each table, total orders, total revenue, and ordered items.

The application also includes a Reservations page where administrators can view all reservations, access reservation details, and create new reservations. The Tables page provides a visual representation of the restaurant layout, showing available, reserved, and occupied tables.

Additionally, the Orders page allows administrators to manage customer orders and create new ones. The Menu page displays the entire restaurant menu with full administrative control to add, edit, or remove menu items.

### Main Features
- MVC architecture in PHP
- Authentication and session management
- MySQL database with phpMyAdmin
- Image upload and processing
- Full CRUD operations
- Restaurant statistics dashboard
- Daily report generation
- Reservations management
- Table status management
- Orders management
- Dynamic restaurant menu management
